# Xunit.OpenCategories
Friendlier attributes to help categorise your tests.

## xUnit Version Support

This library provides support for both xUnit v2 and v3:
- Use `Xunit.OpenCategories` package for xUnit v2
- Use `Xunit.OpenCategories.V3` package for xUnit v3

Both packages share common functionality through the core library, ensuring consistent trait behavior across xUnit versions.
